# Archlord (2006) – Neuerschaffung mit Unreal Engine 5

Zentraler Dokumentations-Hub für das **Archlord-Remake**-Projekt: die Neuerschaffung des MMORPGs Archlord (2006) mit Unreal Engine 5. Dieses Repository enthält Dokumentation und Import-Skripte; das eigentliche Tooling liegt in eigenen Repositories (siehe [Tools](docs/tools/README.de.md)).

> 🔒 Dieses Projekt ist aktuell **privat** und ausschließlich für Forschungs- und Lernzwecke gedacht. Das Originalspiel *Archlord (2006)* ist Eigentum von Webzen. Die Nutzung dieser Tools und Skripte erfolgt auf eigene Gefahr.

## 📖 Dokumentation

| Bereich | Beschreibung |
|---|---|
| [docs/project](docs/project/README.de.md) | Ziele, Umfang und aktueller Fortschritt des Remakes |
| [docs/tools](docs/tools/README.de.md) | Überblick über die Tool-Repositories (Extraktion, Konvertierung usw.) |
| [docs/assets](docs/assets/README.de.md) | Notizen zu Original-Spieldaten und Dateiformaten |
| [docs/scripts](docs/scripts/README.de.md) | Blender-Importskripte für extrahierte Assets |
