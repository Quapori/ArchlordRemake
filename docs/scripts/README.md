# Scripts

Blender import scripts for working with assets extracted by the [tools](../tools/README.md).

| Script | Description |
|---|---|
| [Python/Blender_DFF_import](Python/Blender_DFF_import/README.md) | Batch-converts `.dff` (RenderWare) models to `.blend`/`.fbx` using Blender 3.6 + the DragonFF plugin |
| [Python/Blender_Plugin_Terrain_import](Python/Blender_Plugin_Terrain_import/README.md) | Blender add-on that imports terrain data (meshes, textures, UV maps) from JSON files |
