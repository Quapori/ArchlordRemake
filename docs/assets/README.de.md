# Assets

Notizen und Referenzdokumentation zu Archlords Original-Spieldaten und Dateiformaten (z.B. `.dff`, `.txd`, RenderWare-Chunk-Strukturen, Terrain-/Minimap-Daten, Archivformate). Dieser Bereich ist aktuell ein Platzhalter — Inhalte werden ergänzt, sobald Reverse-Engineering-Erkenntnisse dokumentiert werden.

Für praktische Tools, die mit diesen Formaten arbeiten, siehe [../tools/](../tools/README.de.md).
