# Tools

Überblick über die Tool-Repositories des Archlord-Remake-Projekts. Alle werden im gemeinsamen [Archlord-Remake-Project-Board](https://github.com/orgs/Quapori/projects/2) getrackt.

| Repository | Zweck | Status |
|---|---|---|
| [Quapori/Archlord-AIO](https://github.com/Quapori/Archlord-AIO) | Rust-Tool-Suite zum Extrahieren, Konvertieren und Exportieren von Original-Spieldaten aus Archlord (2006) (DFF/TXD/RW → glTF/PNG/CSV usw.), mit eigenen versionierten Releases | ⚠️ Veraltet — wird durch eine neue Python-basierte Version ersetzt |
| [Quapori/al2extract](https://github.com/Quapori/al2extract) | Eigenständiges CLI-Tool zum Extrahieren von Archlord-2-Client-Archiven (eigenständiges Nebenprojekt, anderes Spiel) | Aktives Nebenprojekt |

*Dieser Bereich wächst, sobald weitere Tool-Repositories zum Projekt hinzukommen.*
