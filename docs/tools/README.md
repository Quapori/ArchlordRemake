# Tools

Overview of the tooling repositories used by the Archlord Remake project. All are tracked on the shared [Archlord Remake project board](https://github.com/orgs/Quapori/projects/2).

| Repository | Purpose | Status |
|---|---|---|
| [Quapori/Archlord-AIO](https://github.com/Quapori/Archlord-AIO) | Rust tool suite for extracting, converting and exporting original Archlord (2006) game assets (DFF/TXD/RW → glTF/PNG/CSV, etc.), with its own versioned releases | ⚠️ Deprecated — being replaced by a new Python-based version |
| [Quapori/al2extract](https://github.com/Quapori/al2extract) | Standalone CLI tool for extracting Archlord 2 client archives | Active side project |

*This section will grow as more tooling repositories are added to the project.*
