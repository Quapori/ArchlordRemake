# Project

## 🎮 Description

This project structures and organizes all necessary source data for recreating the MMORPG **Archlord (2006)** with **Unreal Engine 5**. The goal is to preserve the original gaming experience while using modern technology for improved performance and visual quality.

## 📌 Goals

- **Faithful Reconstruction** – based on the original game data and mechanics
- **Optimized Performance** – using modern UE5 rendering technology
- **Extensibility** – room for future modifications or expansions
- **Multiplayer Functionality** – integration of a dedicated server system

## 🔄 Progress

- ✅ Initial asset analysis & import into UE5
- 🔳 Basic movement & controls
- 🔳 Implement combat system
- 🔳 Develop NPC & quest system
- 🔳 Set up multiplayer server
